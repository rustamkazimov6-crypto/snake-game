# Snake Game

A classic Snake game built as a console application in C#.

## Features

- Smooth console rendering with no flicker
- WASD and arrow key controls
- Snake grows when eating food
- Wall and self-collision detection
- Score tracking
- Restart or quit after game over

## Tech Stack

C#, .NET 8, Console I/O, Threading

## How to Run

Make sure you have .NET 8 SDK installed, then:

```
dotnet run
```

## Controls

| Key | Action |
|---|---|
| W / Up | Move up |
| S / Down | Move down |
| A / Left | Move left |
| D / Right | Move right |
| R | Restart after game over |
| Q | Quit |
